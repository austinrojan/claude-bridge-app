Claude Bridge

Claude Bridge is Austin Rojan's personal tool and is not offered to anyone else. It runs on his Mac and receives tasks from an assistant as request files in a folder in his Google Drive.

Privacy policy

Claude Bridge uses one Google permission: read-only access to Google Drive file metadata (the drive.metadata.readonly scope). It does not read file contents.

It reads metadata only for request files in that one folder. For each request, it reads who owns the file, which account last modified it, the folder's sharing permissions, and the file's checksum and modification time. These details let Claude Bridge confirm that the request came from Austin's own account and is unaltered.

Claude Bridge uses the metadata only for this check, which runs on Austin's Mac. It does not share, sell, or transfer the metadata to anyone, and it shows no ads and collects no analytics.

Claude Bridge's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Austin can revoke this access at any time through https://myaccount.google.com/permissions.
